常见问题

如何手动安装到 Hermes？

克隆仓库后，将 skill 目录复制到 Hermes skills 目录，或在 Hermes 中使用 /install-skills 命令指定仓库路径。

这些技能覆盖哪些内容？

89% 的章节内容完全覆盖，包括方法学、框架和原则。11% 部分覆盖 API 实现细节、前沿实验参数等非方法学内容。

原子技能和综合技能有什么区别？

原子技能聚焦单一方法，包含完整的 RIA++ 结构和测试套件；综合技能提供全书框架，包含章节文件、术语表和决策速查表。
