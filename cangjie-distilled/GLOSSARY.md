# GLOSSARY: Key Terms from Chapters 1-5

**Source:** Deep Understanding of AI Agents -- Li Bojie
Definitions are the author specific usage, not generic dictionary definitions.

---

## A

**ACI (Agent-Computer Interface)** -- Designing tool interfaces from the Agent perspective (easy for the Agent to understand and use), analogous to HCI (Human-Computer Interface). Core focus: make tools friendly to Agents, not humans. Includes error-prevention (Poka-yoke) design.

**Advanced JSON Cards** -- A memory storage format with three-level nesting (Category > Subcategory > Key-Value) plus narrative context (backstory), entity identity (person), and relationship to user. Solves disambiguation problems that simple key-value storage cannot. Higher overhead but superior for critical data.

**Agent** -- A system built around an LLM that plans its own execution steps, calls tools, and adjusts strategy based on results. Formula: Agent = LLM + Context + Tools. Not a passive question-answer system.

**Agentic RAG** -- A RAG paradigm where the Agent autonomously decides when to search, what to search for, and whether to continue searching. Turns passive retrieve-generate pipeline into active iterative exploration using the ReAct pattern.

**Append-Only** -- A data pattern where records are never modified or deleted once written; new events are only appended to the end. The trajectory follows this pattern.

## B

**Bitter Lesson (The)** -- Rich Sutton observation that in AI research, general methods that scale with compute and data (search and learning) eventually outperform hand-crafted domain-specific approaches. The book uses this to frame the tension between Harness engineering (human priors) and model internalization.

## C

**Circuit Breaker** -- A mechanism that automatically stops retrying after a certain number of consecutive failures, preventing cascade failures. Used in error recovery and compression failure handling.

**Context** -- The working set of information available to an Agent at each decision point. Includes system prompt, tool definitions, conversation history, retrieved documents, runtime state, and task-specific information. The ceiling of Agent capability.

**Context Engineering** -- Systematically designing and managing what the model sees at each decision point. Goes beyond prompt engineering to manage the full working context. The second wave of AI engineering after Prompt Engineering.

**Context Rot** -- A phenomenon where context fits the window but key information cannot be found because attention weights are spread across too many tokens. More insidious than context overflow (which is visible). Causes decision quality to deteriorate quietly.

**Contextual Retrieval** -- A RAG technique where, before indexing a text chunk, an LLM generates a short prefix summary containing the chunk core context. Re-anchors ambiguous chunks in their original semantic environment. Reduces retrieval failure rate by 49% (with BM25) to 67% (with reranker).

## E

**Enhanced Notes** -- A memory storage format that saves each memory as a paragraph containing complete context. Preserves narrative structure but has storage redundancy and update complexity.

**Externalized Learning** -- One of three Agent learning paradigms. Externalizes knowledge and procedures into knowledge bases and executable tool code. Persistent and interpretable. Complements post-training and in-context learning.

## F

**Fail-Safe Defaults** -- A Constrain principle: all capabilities are off by default and must be explicitly enabled. Similar to mobile app permission management.

## H

**Harness (Harness Engineering)** -- All infrastructure outside the model: Context + Tools + Constrain + Verify + Correct. The engineering that turns a capable model into a reliable agent. As models commoditize, the Harness becomes the competitive advantage. The third wave of AI engineering.

**Human-in-the-Loop** -- A protective measure where an Agent hands over control to a human at critical decision points. Triggered by exceeding failure thresholds or encountering high-risk operations.

## I

**In-Context Learning** -- One of three Agent learning paradigms. Adapts on the fly through pattern retrieval within the context via the attention mechanism. Fast but transient (disappears when session ends). Its inner mechanism is closer to pattern matching than true learning.

**Input Isolation** -- A Verify principle: security checks only look at structured data (JSON from tools), not free-form text generated by the model, because attackers might manipulate model output through prompt injection.

## K

**KV Cache** -- A mechanism for reusing historical computation results during LLM inference. The key-value pairs of the attention mechanism are cached so they need not be recomputed. Requires context prefix to remain unchanged for cache hits.

## L

**Lethal Triad** -- Simon Willison concept: when an Agent has (1) access to private data, (2) exposure to untrusted content, and (3) ability to communicate externally, a complete attack loop is formed. The book adds a fourth amplifier: Persistent Memory.

**Loop Engineering** -- The newest wave of AI engineering. Widens the view from a single run to sustained autonomous operation across runs: who discovers the next piece of work, when to verify, and when the task counts as truly done.

## M

**Meta-capability (Code)** -- The ability to create new tools and capabilities dynamically at runtime. Code generation is not one tool in the toolbox but the means to make any tool. The core of general-purpose Agents targeting open-ended tasks.

**MCP (Model Context Protocol)** -- A standard protocol for tool interoperability that decouples tool definitions from the Agent framework. Tools are grouped by server (like apps on a phone).

**MCP-Zero** -- A proactive tool discovery approach where the Agent declares what capability it needs in natural language and the system matches and injects the tool on the fly via two-level semantic matching. Reports ~98% token savings on ~2800 tools.

## P

**Poka-yoke** -- A Japanese manufacturing term (from Toyota Production System) for error-prevention design. Applied to tool design: make interfaces that prevent likely mistakes, like a USB connector that fits only one way.

**Post-training** -- One of three Agent learning paradigms. Encodes experience into model parameters through reinforcement learning. Strongest cross-task generality at highest update cost.

**Progressive Disclosure** -- A context engineering pattern (also called Skills) where detailed instructions are loaded only when the current context demands them. Like consulting a reference book index, not reading it cover to cover.

**Prompt Injection** -- An attack where malicious instructions are embedded in external data (web pages, documents) that the Agent processes. Differs from jailbreak: in jailbreak the user attacks directly; in prompt injection the attacker manipulates indirectly through data.

**Proposer-Reviewer Pattern** -- A verification method where one Agent proposes a solution and another (or the same Agent in a different role) reviews it before action proceeds. Ensures verification -- not the model own feeling -- decides when a task ends.

## R

**ReAct Loop** -- The core operating loop of an Agent: Think (reason about the next step), Act (call a tool), Observe (process the tool result). Repeat until task complete.

**Reasoning** -- The model step-by-step thinking (chain-of-thought, reasoning tokens). Distinct from Inference (forward computation at deployment time).

**Inference** -- The model forward computation at deployment time (inference cost, inference stack). Distinct from Reasoning.

## S

**Sessionless Design** -- An interaction paradigm with no installation, login, or open-app steps. The Agent is always online. Requires persistent file system state and process state management across messages that may be days apart.

**Sidecar** -- An independent review mechanism outside the main Agent context. Used for approving high-risk operations. An Agent within the same context cannot reliably determine if it has been compromised, so critical operations must be reviewed externally.

**Simple Notes** -- A minimalist memory storage format where each memory is a minimal, indivisible fact. O(1) operations but loses associations between related facts.

**Skills** -- See Progressive Disclosure. Modular capability documents loaded on demand. At startup the Agent sees only a thin catalog (name + description).

**Sub-Agent Context Isolation** -- A pattern where the main Agent delegates tasks that generate large amounts of intermediate content to a sub-agent. The sub-agent completes exploration in its own context and returns only a concise summary. Replaces post-hoc compression with upfront isolation.

## T

**Three-Level Memory Framework** -- An evaluation framework: Level 1 (Basic Recall), Level 2 (Multi-Session Retrieval), Level 3 (Proactive Service). Each level is strictly harder. Level 3 requires both global overview and precise details.

**Tool Calling (Function Calling)** -- A core LLM capability that lets the model invoke external tools in a structured way. The model decides whether to call, which tool, and what arguments; the framework executes.

**Trajectory** -- The complete historical record of a single Agent run: user messages + model replies + tool execution results. Appended chronologically, never modified (append-only).

**Two-Tier Memory Architecture** -- Tier 1: Advanced JSON Cards (key facts resident in context as overview). Tier 2: Contextual Retrieval (on-demand detail from raw conversations). Together they enable Proactive Service (Level 3 memory).
